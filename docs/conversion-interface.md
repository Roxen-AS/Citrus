# Converting files in Citrus

Add local files with **Add files…**, or drop them into the main window. Use **Remove** or **Clear** to change the selection. Convert and Tools show the intersection of operations supported by every input. The Explorer wheel offers the same catalogue: tap Shift for Convert or Alt for Tools during a file drag, then drop on an operation. Releasing the key leaves the wheel open; the center or Escape cancels.

Image, PDF, subtitle and archive engines are available locally. The current preview also registers document/presentation/spreadsheet/EPUB conversion when the pinned offline feature pack is present, and validates genuine HEIC and ExifTool capability. Media discovery runs in the background against the bundled FFmpeg/FFprobe files, including the conditional Windows H.264 encoder probe. If a pack is missing or discovery fails, unavailable routes are omitted and the app shows repair information while retaining other engines. It never downloads engines at runtime.

Ordinary format conversions submit one independent job per input; errors do not stop unrelated jobs. The retained generic options/group confirmation uses **Create copies**. Requested visual tools instead open their proper editor and use **Apply**, **Compress**, **Save**, **Save with Background** or **Save Bleeped Copy**. They share an opaque-white shell in both themes, dark text, a centered title independent of the right close button, common controls and reachable fixed footer actions. Canvases, metadata tables and audio waveforms retain distinct layouts.

Group operations (merge PDF, images to PDF, ZIP and TAR) require confirmation even when they need no parameters. The input list preserves incoming order; Move up/down changes it. The first input supplies the output name. A group from one folder defaults to that folder; mixed-folder groups require an explicit **Choose folder…** choice. Canceling the editor flow submits none of its unqueued accepted drafts. Closing a dirty editor asks for discard through its supported close state; it does not publish a partial recipe.

Options cover resize (positive dimensions, aspect ratio on by default), image quality (1–100, default 85), rotation, trim (seconds), speed (0.25–4), normalization (-70 to -5 LUFS, default -16), and PDF pages (blank means all; `1,3-5` selects ordered pages). Trim end must fit within every readable selected input. PDF ranges are checked against every readable page count before submission. An unreadable input receives its own failed job; valid siblings can still run. Plain format conversions use the engine presets without an additional dialog.

Each job displays its source, operation, state, progress, warnings/reconstruction limitations and actual output names. Progress remains indeterminate when the engine has no meaningful percentage. **Cancel** requests cancellation of queued/running work. **Retry** creates a new job using the previous options/accepted recipe, with confirmation again where needed. **Choose folder…** on a failed job retries into a chosen destination; it never elevates privileges. **Reveal** opens Explorer at a committed output. Existing outputs and originals are never overwritten by conversion.

The window lists session-only history. Closing it leaves Citrus in the tray; Open Citrus restores it, Pause drag gestures pauses capture, and Quit cancels workers. Work uses at most two concurrent conversions by default.

## Availability and limits

Unsupported operations are omitted, and submission is disabled when the entire selection has no common operation. Requested image/media/PDF tools route through typed editors; Office/EPUB format workflows use the installed offline engine pack. PAGES destinations are clearly labeled DOCX compatible with Apple Pages and save `.docx`, not a renamed `.pages`. Folders and offline cloud placeholders cannot enter the conversion selection.

Still-image operations reject animated/multipage images. The distinct **GIF still image** and **GIF animation** choices identify the image and media routes; they keep separate stable operation IDs. SVG is input-only. HEIC requires actual encode/decode validation. H.264 appears only after the local encoder probe succeeds. ZIP/TAR groups reject duplicate basenames; existing archive conversion repacks members instead of nesting the original archive. Compound `.tar.gz`/`.tgz` extracts members in one operation; arbitrary nested archives are not recursively expanded. Archive extraction caps are 100,000 entries and 20 GiB expanded data. Encrypted PDFs remain unsupported; OCR and editable reconstruction are available with the offline dependencies, with best-effort warnings.

The current build is a Windows preview. The [83-entry / 81-operation checklist](reference-operation-verification.md) tracks entry points separately from complete native acceptance. Linux cross-compilation, backend tests and scaled WPF rasters do not establish Explorer, native playback, accessibility, high-contrast, physical DPI or reference fidelity. The [verification ledger](reference-feature-coverage.md) records current native guard failures, tested cancellation behavior and missed performance gates. Clean-machine deployment and clean-checkout pack acquisition also remain unqualified.
