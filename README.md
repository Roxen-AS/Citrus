# Citrus

A local file converter for Windows with a tray app, drag-and-drop wheel, and file workspace.

**Current preview:** 0.3.0-preview.1 · Windows x64 · unsigned

[Download the tested preview](https://github.com/Skytuhua/Citrus/actions/runs/39238359290/artifacts/12180558101) · [View source code](https://github.com/Skytuhua/Citrus/tree/citrus/tangerine-parity)

## Features

- Local image, audio, video, PDF, subtitle, and archive conversion.
- Image cropping, adjustments, resizing, rotation, annotation, and manual privacy masks.
- Collision-safe output copies that preserve originals.
- Light/dark themes, animations, and optional sound effects.

## Quick start

1. Download the preview artifact while signed in to GitHub and extract the ZIP.
2. Quit and uninstall an earlier Citrus preview, then run **Citrus-Setup.exe**.
3. Start dragging files, then tap **Shift** to convert, **Alt** for tools, or **Ctrl** for file actions. Release the key and drop on a choice. **Escape** or the center cancels.

The installer includes .NET and conversion engines. No administrator rights are needed. The temporary download expires January 17, 2027, unless removed earlier.

## Status

The tested preview passed 281 Windows desktop checks, with four skipped. Live Liquid Glass remains disabled; physical Explorer selection, mixed-monitor DPI, and full Tangerine parity remain in progress.
