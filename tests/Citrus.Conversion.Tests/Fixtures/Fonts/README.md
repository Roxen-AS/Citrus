# Original, redistributable font fixtures

These are original geometric glyph outlines generated by `generate.py` with local
fontTools 4.61.1. No installed font or downloaded asset is copied. The ASCII,
number and Chinese codepoints deliberately use simple known-answer silhouettes;
these are coverage/layout fixtures, not fonts intended for readable UI text.
Two distinct faces have different advances and silhouettes. The TTC contains both
in that order, for actual FaceIndex ownership tests. Timestamps are fixed.
